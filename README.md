# 🚀 CareerPilot AI

CareerPilot AI is a web application built using Python, Django, and MySQL to help students and job seekers prepare for their careers.

## Features

- 👤 User Registration & Login
- 📄 Resume Builder
- 💼 Job Recommendations
- 🤖 AI Career Guidance
- 🎤 Interview Preparation
- 📊 User Dashboard

## Tech Stack

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap
- Git & GitHub
